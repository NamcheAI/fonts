# Upstream provenance

This directory is an immutable safecopy of the Geist sources that Michael
Marte retained while developing Namche Shadow. The exact source commit of the
original safecopy was not recorded in the initial repository history.

The repository structure and automation were compared with
`vercel/geist-font` commit `10dc7658f13c38a474cde201bb09a4617267545b` on
2026-08-13. Files in this directory intentionally keep their original Geist
names, copyright notices, and metadata.

Do not edit this directory. Make all derivative changes in the root
`sources/` tree.
