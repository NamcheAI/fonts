# Namche-Shadow (RoundCorner)

Production path: **Glyphs RoundCorner export filters** on Geist Sans upright sources. Delivery family name: **Namche-Shadow**.

## Filter parameters

| Filter | Radius | Mode |
|--------|--------|------|
| Caps + figures + cap/figure-like glyphs | `−40` | `include` |
| All other glyphs | `−25` | `exclude` (same glyph set) |

Strong set = Uppercase class ∪ decimal digits (and variants) ∪ currency / fraction / superior-inferior / `&` `@` etc. Minuscule `germandbls` stays on the mild (`−25`) side; cap `Germandbls` is strong.

**Variable instance:** keep RoundCorner filters **disabled**. Glyphs reports incompatible masters when the filter is applied to VF export.

## Paths

| Path | Role |
|------|------|
| `../geist-font-original/` | **Immutable** pristine Geist Sans upright sources |
| `../sources/Geist.glyphspackage` | Working package (`fontinfo.plist` holds filters) |
| `apply_roundcorner_filters.py` | Writes Filter custom parameters on static instances |
| `roundcorner_caps_figs_filters.txt` | Paste-ready filter strings (regenerated by the script) |
| `inner_round_app.py` | Local static specimen UI |
| `../exports/Namche-Shadow/` | Delivery: `otf/`, `woff/`, `woff2/`, `ttf/`, `.glyphspackage` |

`geist-font-main.zip` is **not** used as the original.

## Apply filters

```bash
cd geist-font-main
python3 scripts/apply_roundcorner_filters.py
# or:
python3 scripts/apply_roundcorner_filters.py --package sources/Geist.glyphspackage
```

- Updates every **static** instance `customParameters` with the include/exclude RoundCorner pair.
- Skips `type = variable`.
- Rewrites `scripts/roundcorner_caps_figs_filters.txt` for manual paste in Glyphs if needed.

**Never edit files under `geist-font-original/`.**

## Export from Glyphs

1. Open `sources/Geist.glyphspackage` (or a renamed export package).
2. Confirm static instances have both RoundCorner filters enabled; variable instance filters stay disabled.
3. Export static OTFs (Thin → Black).
4. Optionally export the variable font **without** RoundCorner filters.
5. Rename family / files to **Namche-Shadow** and build `woff` / `woff2` into `exports/Namche-Shadow/`.

## Local specimen (static files)

```bash
cd geist-font-main
python3 scripts/inner_round_app.py
# → http://127.0.0.1:8765
```

Serves `exports/Namche-Shadow/woff2/` (preferred), then `woff/`, then `otf/`. Weight + size controls only — no live RoundCorner.

Uses `.venv-inner-round` automatically when present.

## Future idea (not implemented)

Dual interactive sliders for include/exclude radii that rewrite `fontinfo.plist` and/or switch **pre-exported** preset packs in the specimen UI.

Live Glyphs RoundCorner in the browser is **not** possible: the filter runs only inside Glyphs at export time. Any true radius change needs a re-export (or a separate approximation that will not match Glyphs).

## Legacy

`round_inner_corners.py` is an experimental Python inner-fillet engine from an earlier approach. It is **not** the shipping pipeline for Namche-Shadow.
