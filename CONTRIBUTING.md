# Contributing to Namche Shadow Sans

Thank you for helping improve Namche Shadow Sans. The project follows the structure
and build workflow of [Vercel's Geist font](https://github.com/vercel/geist-font).

## Before opening a pull request

1. Keep `originals/geist/` unchanged; it is the provenance archive.
2. Make source changes under `sources/` and tooling changes under `scripts/`.
3. Run `make build` and `make test`.
4. Describe any visible outline or metric changes and include a proof when
   appropriate.
5. Preserve `OFL.txt`, the original Geist credits, and the Namche Shadow Sans design
   credit.

Use a Conventional Commit title. Changes land through a reviewed pull request;
do not push directly to `main`.
